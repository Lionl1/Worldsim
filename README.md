# worldsim

Физические модели миров на Rust для симуляции и генерации обучающих данных.
Без внешних зависимостей — только `std`.

```bash
cargo build --release
./target/release/worldsim validate        # проверить все законы (31 проверка, ~0.1 с)
cargo test --release                      # то же как тесты
```

## Пресеты и их смешивание

Мир собирается из трёх независимых слоёв:

| слой | пресеты | что содержит |
|---|---|---|
| физика | sun, mercury, venus, earth, moon, mars, jupiter | GM, радиус, вращение, J2, альбедо, магнитный диполь, орбита J2000 |
| атмосфера | none, earth, mars, venus, jupiter | давление, состав газов, профиль T, парниковая оптическая толщина |
| поверхность | earth, moon, moon_mare, mars, venus, mercury | состав коры (оксиды → элементы), теплофизика грунта |

```bash
worldsim info mars                                             # всё от Марса
worldsim info --physics mars --atmosphere earth --surface moon # Марс + воздух Земли + лунный грунт
worldsim info earth --gravity-scale 1.5 --distance-au 1.3      # «суперземля» дальше от звезды
```

При смешивании производные величины **пересчитываются из законов**, а не копируются:
давление по высоте — заново из гидростатики с гравитацией нового тела, парниковая τ — пропорционально
массе столба газа (P/g), температура поверхности — из радиационного баланса.
Пример: земной воздух на Марсе даёт шкалу высот 20.8 км и T ≈ 270 К.

## Что моделируется

| модуль | законы |
|---|---|
| `nbody` | всемирное тяготение; симплектический интегратор Йошиды 4-го порядка; опционально 1PN-поправка ОТО (`--gr`) |
| `ballistics` | 2-й закон Ньютона во вращающейся системе: Кориолис, центробежная сила, сжатие J2, сопротивление ½ρC_dAv², закон Архимеда |
| `atmosphere` | гидростатика dP/dz = −ρg(z), уравнение идеального газа, соотношение Майера (γ), скорость звука |
| `thermal` | инсоляция (обратные квадраты + зенитный угол), Стефан–Больцман, закон Фурье, 1-е начало, парниковое противоизлучение |
| `magneto` | сила Лоренца, СТО (релятивистский пушер Бориса), поле диполя, радиационные пояса |
| `presets` | стехиометрия: оксиды → элементы с сохранением массы |

## Проверка законов (`worldsim validate`)

Каждая проверка сравнивает симуляцию с законом сохранения, аналитикой или наблюдениями:

- энергия, импульс, момент импульса Солнечной системы за год: дрейф ~10⁻¹³–10⁻¹⁵
- прецессия перигелия Меркурия от ОТО: 42.7″/век (теория 43.0″)
- 3-й закон Кеплера, падение с отклонением Кориолиса (22.0 мм, теория 22.0 мм)
- атмосфера Земли: ρ₀ = 1.225 кг/м³, P(11 км) = 22 646 Па (US Std: 22 632), c = 340.3 м/с
- температуры: Земля 288 К, Венера 735 К, Луна 97–386 К (Diviner: ~95–390), Марс 175–279 К
- 1-е начало: E − E₀ = работа сопротивления с точностью 10⁻¹²; невязка теплового баланса 10⁻¹⁵
- зеркальные точки частиц в поясах совпадают с теорией адиабатического инварианта

## Генерация датасетов

```bash
worldsim dataset --task projectile --n 10000 --worlds earth,moon,mars,mars:earth:moon --out data/proj --seed 1
worldsim dataset --task orbit     --n 5000 --worlds earth,moon,mars --out data/orb
worldsim dataset --task thermal   --n 2000 --worlds moon,mars,earth --out data/therm
worldsim dataset --task particle  --n 1000 --worlds earth,jupiter --out data/belts
worldsim dataset --task system    --n 500  --out data/systems          # случайные планетные системы
```

Опции: `--points 100` (точек на ряд), `--noise 0.01` (добавит `series_noisy.csv` с шумом измерений),
`--strict` (отбрасывать сэмплы, не прошедшие проверку закона сохранения), `--seed` (воспроизводимость).

Выход: `params.csv` (параметры + итоги + `validation_error`, `valid`), `series.csv` (временные ряды),
`meta.json` (миры, seed, константы, статистика). Формат `world` в CSV: `physics=…;atmosphere=…;surface=…`.

## Отдельные симуляции

```bash
worldsim throw mars --speed 100 --elev 45 --radius 0.05 --density 7800 --out traj.csv
worldsim thermal moon --lat 30 --dec 0 --out moon_day.csv
worldsim particle earth --species electron --mev 2 --L 4 --pitch 30
worldsim system --bodies sun,earth,moon,mars,jupiter --years 10 --dt-hours 2 --gr --out solar.csv
```

## Как библиотека

```rust
use worldsim::world::{World, WorldSpec};
use worldsim::ballistics::{simulate, Launch, Options, Projectile};

let w = World::build(&WorldSpec { physics: "moon".into(), atmosphere: Some("earth".into()),
    surface: None, gravity_scale: 1.0, distance_au: None })?;
let r = simulate(&w, Projectile::sphere(0.1, 1000.0),
    Launch { lat: 0.0, lon: 0.0, altitude: 0.0, speed: 50.0, elevation: 45.0, azimuth: 90.0 },
    Options::default());
```

## Честные границы модели

Это классическая физика + СТО + 1PN ОТО. Не моделируется: квантовые эффекты, полная ОТО
(сильные поля), динамика атмосферы (ветер, погода, конвекция), облака и сезонный CO₂-цикл Марса,
тектоника и внутреннее строение, химические реакции, J2 в задаче N тел. Атмосферы — сферически
симметричные, серые по ИК. Значения пресетов — средние, округлённые.

## Куда расти к «модели вселенной»

1. Звёзды как пресеты (масса → светимость, спектр Планка) и генератор звёздных систем с обитаемой зоной.
2. Многослойный перенос излучения вместо серой модели; спектральные полосы CO₂/H₂O.
3. Барнс–Хат или FMM для N ~ 10⁵–10⁶ (скопления, галактики) и космологический фон (Фридман).
4. Динамика атмосферы (уравнения мелкой воды на сфере) — циркуляция и климат.
